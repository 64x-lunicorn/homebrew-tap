# Homebrew tap for LogSquirl

[LogSquirl](https://github.com/64x-lunicorn/LogSquirl) is a fast, smart log file explorer.

```sh
brew install --cask 64x-lunicorn/tap/logsquirl
```

Update with `brew upgrade --cask logsquirl`. Requires Apple Silicon and macOS 15 or later.

CI Release of LogSquirl updates the cask on every stable release; please report problems in the
[LogSquirl issue tracker](https://github.com/64x-lunicorn/LogSquirl/issues), not here.
